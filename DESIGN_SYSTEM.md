# Golden Plate — Design System

The look of the site is driven entirely by **design tokens** in [`src/styles/tokens.css`](src/styles/tokens.css).
Components never use raw colour values; they use semantic tokens through Tailwind utilities
(`bg-surface`, `text-text-muted`, `border-border`, `shadow-md`) or `var(--color-…)` in CSS.

Live reference: **`/design-system`** (open in development; in production it requires an admin login,
or set `DESIGN_SYSTEM_PUBLIC=true`).

---

## How to rebrand

| Change | Edit |
| --- | --- |
| Colours | `src/styles/tokens.css` → **Primitives** (`--palette-*`). Semantic tokens point at primitives, so most rebrands only touch primitives. |
| Which primitive a role uses | `src/styles/tokens.css` → **section 3** (`--color-bg: light-dark(<light>, <dark>)`). |
| Fonts | `src/styles/fonts.ts` (which Google font is loaded) + the fallback stacks for `--font-display` / `--font-body` in `tokens.css`. |
| Name, tagline, phone, WhatsApp, email, hours, address, socials, reference prefix | `/admin` → **Brand Settings** (no deploy needed). Defaults: `src/config/brand.ts`. |
| Logo | Drop SVGs into `public/brand/` with the same filenames, or upload them in Brand Settings. The placeholder is generated by `npm run generate:logo`. |

After changing colours run `npm run check:contrast`. It fails if any required pair drops below WCAG AA in either theme.

## Token architecture

```
Primitives  (--palette-gold-500, --palette-ivory …)        raw values, not exposed to Tailwind
     │
     ▼
Semantic    (--color-bg, --color-accent, --shadow-md …)    light-dark(<light>, <dark>), per role
     │                                                      declared on :root AND every [data-theme]
     ▼
Utilities   bg-bg · text-accent · border-border-input …    via `@theme inline reference`
```

- **Theme switching.** `next-themes` sets `data-theme="light|dark"` and `color-scheme` on `<html>`
  before first paint, so there is no flash. Each semantic token is written once as
  `light-dark(light, dark)`.
- **Nested themes.** Because semantic tokens are re-declared on every `[data-theme]` element,
  any subtree can force a theme: `<section data-theme="dark">` gives a dark band inside a light page.
- **Tailwind defaults are removed** (`--color-*: initial`, etc.), so `bg-amber-500` does not exist.
  `npm run check:colors` also fails on hex / `rgb()` literals in components and pages.

### Colour roles

| Token | Use |
| --- | --- |
| `bg`, `bg-subtle` | Page background, alternate bands |
| `surface`, `surface-raised`, `surface-sunken` | Cards, popovers/drawers, wells |
| `text`, `text-muted`, `text-inverse` | Body copy, secondary copy, text on inverted blocks |
| `accent` | Links and gold text (bronze `#7A5E22` in light mode for AA contrast) |
| `accent-display` | Large display type only (deep gold in light mode; ≥ 3:1) |
| `accent-fill`, `accent-fill-hover`, `on-accent` | Primary button and gold fills; text on them |
| `accent-soft` | Selected chips/cards, subtle highlights |
| `secondary`, `secondary-fill`, `on-secondary` | Banana-leaf green accents |
| `border`, `border-strong`, `border-input`, `border-accent` | Dividers, emphasis, form controls (≥ 3:1), gold rules |
| `focus-ring` | Keyboard focus outline |
| `success`, `warning`, `danger`, `on-danger` | Status. Chili/danger is for errors only. |
| `diet-veg`, `diet-nonveg`, `diet-jain` | FSSAI-style diet marks |
| `scrim` | Overlay behind modals and drawers |

`--gradient-gold` (logo mark, key dividers, CTA sheen) and `--gradient-sheen` are **decorative only, never for text**.

### Typography

- **Display:** Fraunces (variable: optical size and `SOFT` axes). Headlines are set large with tight tracking.
- **Body/UI:** Inter Tight.
- **Fluid scale:** `text-xs` … `text-5xl`, `text-display`, each `clamp()`ed between a 360px and a 1440px viewport. Every size has a matching line height.
- **Tracking:** `tracking-display` (−0.03em), `tracking-tight`, `tracking-wide`, `tracking-caps` (0.24em, used by `.eyebrow`).
- **Numbers:** prices use `.tabular` (tabular, lining numerals) and `formatINR()` for en-IN grouping (₹1,50,000).

### Space, shape, depth, layers

- **Spacing:** Tailwind's `--spacing` (0.25rem) scale, plus `--spacing-gutter` (page side padding), `--spacing-section` (vertical rhythm) and `--spacing-stack-{sm,md,lg}`.
- **Radii:** `xs` 2px · `sm` 4px · `md` 8px (cards) · `lg` 16px · `xl` 28px · `full` (buttons, chips — the plate motif).
- **Elevation:** `shadow-sm|md|lg|overlay|glow`. These are warm drop shadows in light mode and become soft golden glows with a hairline highlight in dark mode.
- **Z-index:** `--z-base` < `raised` < `sticky` < `header` < `overlay` < `drawer` < `modal` < `popover` (menus/pickers, also inside dialogs) < `toast` < `cursor` < `transition`.
- **Containers:** `.container-content` (72rem), `.container-wide` (90rem), `max-w-prose` (68ch).

### Motion

- **Durations:** `--duration-instant|fast|base|slow|slower|ambient`.
- **Easings:** `ease-standard`, `ease-out-expo` (entrances), `ease-in-out-quart` (curtains), `ease-spring-soft`.
- **Stagger:** `--stagger-xs|sm|md`.
- **JavaScript mirror:** `src/lib/motion/tokens.ts`. A unit test keeps it equal to `tokens.css`.
- **Rules:** animate only `transform` and `opacity`. Under `prefers-reduced-motion` all transitions and animations collapse to near-instant (global rule in `globals.css`).

## Components (`src/components/ui`)

| Component | Notes |
| --- | --- |
| `Button` | `primary` (gold fill + sheen on hover), `secondary`, `leaf`, `ghost`, `link`; sizes `sm`, `md`, `lg`, `icon`; `loading`; `asChild` for links |
| `Link` | `inline` (always underlined) or `nav` (underline draws in). External links open in a new tab and announce it. |
| `Badge`, `DietTag`, `DietMark` | Diet tags use FSSAI marks plus a text label |
| `Card` (+ `CardMedia`, `CardBody`, `CardTitle`, `CardDescription`, `CardFooter`) | `interactive` lifts on hover and focus |
| `Chip`, `FilterChip` | Filter chips are toggle buttons (`aria-pressed`) |
| `Field` + `Input`, `Textarea`, `PhoneInput`, `Select`, `DatePicker`, `Stepper` | `Field` wires the label, hint, error and `aria-*` attributes automatically |
| `Checkbox`, `CheckboxCard`, `RadioCard(Group)` | The tick draws in. Whole cards are clickable and keyboard accessible. |
| `Modal`, `Drawer` (`right` / `bottom`) | Radix Dialog: focus trap, Esc to close, focus restored on close |
| `Tabs`, `Accordion` | Radix. The accordion animates opacity and transform only. |
| `Toaster` / `toast()` | sonner, themed with tokens; lazy-mounted on idle. Import `toast` from `ui/toast` |
| `Skeleton`, `Spinner` | The spinner is a plate rim with a travelling highlight |
| `Price` | ₹ with en-IN grouping, `per="plate"`, `compact` (₹1.5L) |
| `AnimatedPrice` | Total that counts to its new value (easing token), instant under reduced motion; screen readers get the final value only |
| `Slider` | Range/single slider (Radix), 24px thumbs, spoken values via `formatValue` |

Brand: `Logo`, `LogoMark` (`src/components/brand`) are inline SVGs coloured by tokens, so they switch with the theme.
The `data-cursor="…"` attributes on interactive elements are hooks for the custom cursor (Phase 5).
